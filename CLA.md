## How to accept

A bot comments on your first pull request. Reply with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Once, ever. Your signature is recorded in this repository, in
`.github/cla/signatures.json`, alongside the pull request that carried it.

If you would rather not agree, that is entirely reasonable — open an issue
instead. A well-described bug report is worth more to this project than a patch
we cannot accept, and it costs you nothing.
